# Changelog

## 1.0.1 — 2026-10-24
- Before moving an item to the Trash, Prune checks that it's still where the last scan found it, and skips it if it changed.
- Put Back moves items only out of the Trash, and only to where they came from.
- Scan results and History can be read only by your user account.
- Logs are listed by app.
- Removing snapshots asks for an administrator password only when it's needed.
- A Google Drive folder can no longer be selected as a whole.

## 1.0.0 — 2026-10-24
- Scans your whole startup disk in under a minute and shows what's using space, folder by folder.
- Recommendations for caches, old downloads, developer files, large files, duplicates and data from uninstalled apps.
- Selected items move to the Trash, and you can put them back from History.
- Shows available space the way Finder does, including space held by local Time Machine snapshots, and can remove those snapshots.
- Seven color schemes, plus light and dark appearance.
